# iron-lung-timeline

a detailed second-by-second timeline of the movie Iron Lung (2026). not affiliated with the movie or markiplier. coded by [@the-hadiqa](https://www.tumblr.com/the-hadiqa) using the movie’s timestamp breakdown created by [@negative-pressure-ventilator](https://www.tumblr.com/negative-pressure-ventilator) and the injuries masterlist created by [@ctrl-shift-alt-9](https://www.tumblr.com/ctrl-shift-alt-9), [@tabletoptime](https://www.tumblr.com/tabletoptime), ji, dusty and [@water-activated-light](https://www.tumblr.com/water-activated-light). all this and more materials are part of [the master reference]/https://drive.google.com/drive/folders/1oTalXMdAi_uw0995qGEgebZnRjqnfHJE) curated by [@ctrl-shift-alt-9](https://www.tumblr.com/ctrl-shift-alt-9).

what’s what:
- index.html, style.css, script.js, iron-lung-logo.webp, favicon.ico, folder fonts - the page itself.
- folder captures - captures from the movie’s diegetic camera, taken from the timestamp breakdown.
- timeline.csv - a table serving as basis for the page, roughly based on the timestamp breakdown from the master reference, with material from the injury masterlist added in.
- csvtohtml.py - used to generate the html from timeline.csv.
